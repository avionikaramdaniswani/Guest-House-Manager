Buatkan website manajemen guest house bernama "Wisma Eucaliptus / Guest House Deluxe" untuk digunakan oleh staf dan resepsionis internal. Website ini adalah sistem Property Management System (PMS) sederhana berbasis web.

## Stack Teknologi
- Frontend: React + Vite
- Styling: Tailwind CSS
- Routing: React Router v6
- State Management: Zustand
- Grafik: Recharts
- Cetak struk: React to Print
- Backend: Node.js + Express
- Database: SQLite (better-sqlite3)
- Tidak perlu auth kompleks — cukup PIN 4 digit untuk masuk

## Fitur Utama

### 1. Dashboard Utama
- Statistik real-time: total kamar, terisi, tersedia, long stay
- Occupancy rate hari ini dalam bentuk angka & progress bar
- Daftar check-in dan check-out hari ini
- Notifikasi kamar yang perlu perhatian (hampir expired long stay, dll)

### 2. Denah Kamar Interaktif (Fitur Utama)
- Tampilkan floor plan visual sesuai layout berikut:
  - Blok A (atas): kamar 21**, 23***, 27***, 31***, 33, 22**, 24***, 30***
  - Blok C (kiri): kamar 1*–19* (ganjil & genap, dua kolom)
  - Blok D/E (tengah): kamar 34**–49* (dua kolom kiri-kanan)
  - Blok G (bawah): kamar 50*–63***
- Kode kamar: * = Double Bed (1-2 orang), ** = Family Room (1-3 orang), *** = Long Stay/Big Room
- Warna status:
  - Hijau = Tersedia
  - Kuning = Terisi tamu reguler
  - Oranye = Long Stay Jepang
  - Biru = Long Stay Lokal
  - Abu-abu = Fasilitas (dapur, laundry, storage, office)
- Klik kamar → slide panel dari kanan berisi:
  - Info kamar (tipe, luas, harga, fasilitas)
  - Info tamu aktif (jika terisi)
  - Tombol aksi: Check-in / Check-out / Edit / Blokir

### 3. Manajemen Tamu & Booking
- Form check-in: nama, KTP/paspor, asal negara, tanggal masuk-keluar, kamar, harga deal, deposit
- Form check-out: ringkasan tagihan, metode bayar, tombol cetak struk
- Booking advance dengan status "Reserved"
- Long stay: set durasi kontrak, tandai negara asal

### 4. Laporan & Statistik
- Laporan harian: tamu masuk/keluar hari ini
- Laporan bulanan: occupancy rate, pendapatan, jumlah tamu per negara
- Grafik hunian mingguan/bulanan dengan Recharts
- Export ke PDF (window.print) dan Excel (SheetJS)

### 5. Fitur Tambahan
- Catatan per kamar (notes)
- Log aktivitas staf
- Responsif untuk tablet
- Dark mode toggle

## Data Awal (Seed Database)
Buat seed script dengan data kamar lengkap sesuai denah. Status awal Juni 2026:
- Kamar 23, 24, 27, 30, 31, 55, 61, 63: Long Stay Jepang (check-out 31 Des 2026)
- Kamar 54, 60: Long Stay Lokal *** (check-out Agustus–September 2026)
- Kamar 8, 10: Long Stay Lokal * (check-out Juli 2026)
- Kamar 22, 36, 39, 48: Terisi tamu reguler (check-out minggu ini)

Harga kamar:
- Tipe * (Double Bed): Rp 220.000/malam
- Tipe ** (Family Room): Rp 350.000/malam
- Tipe *** (Long Stay/Big Room): Rp 450.000/malam
